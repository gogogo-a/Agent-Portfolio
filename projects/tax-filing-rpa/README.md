# 企业所得税自动填表

从金蝶取出薪酬相关金额，登录电子税务局，把季报里三个字段填上并暂存。

## 有什么不一样

- 三个数字来源清楚：从业人数来自配置；另外两个来自金蝶同一科目的贷方、借方累计
- 登录、取数、填报分开，坏了好查
- 本地已有表可以先读表补数；没有待办就跳过登录取数
- 账号密码只放本机，不进仓库

## 流程

```text
初始化 → 登录金蝶 → 取数 → 登录税局 → 填三个字段 → 暂存 → 写进度
```
