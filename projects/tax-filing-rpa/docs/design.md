# 企业所得税 A 表 RPA · 详细设计

## 流程划分

| 流程 | 范围 |
|------|------|
| 登录 | 登录 → 应用 → 总账 → 账表查询 → 科目余额表 |
| 取数 | 过滤 → 组织/期间 → 查询 → 下载 → 解析写进度 |
| 填报 | 登录电子税务局 → A 表三字段 → 暂存 |

## 目录约定（示意）

```text
Conf/登记表.xlsx
Log/{run_id}/运行日志.xlsx
Result/{年}/第{季}/取数进度.xlsx
Result/{年}/第{季}/金蝶取数/{公司}_科目余额表.xlsx
```

## 工程习惯

- 初始化补数：本地已有余额表则跳过金蝶  
- 待办为 0：跳过登录与取数  
- 密钥与账号仅存本机配置，**永不提交**  
- 异常与重试参考通用 RPA 模板（超时、元素等待、截图留证）
