# 工作票智能审核

上传工作票，自动检查有没有违规，并给出能看懂的审核报告。

## 有什么不一样

- 能算清楚的用规则查，要读懂意思的用大模型查，两边一起出结果
- 覆盖 3 种工作票、13 条审核规则
- 一张票大约从人工 3 分钟降到半分钟左右
- 报告里写清违规项、依据和整改建议，用代码按模板拼好，不让模型随便排版
- 准备了通过、等级不对、人数对不上、时间地点不对、措施冲突等测试题；改规则后准确率大概提高一成多

## 背景

人工一张张对计划和票面又慢又容易标准不一，需要稳定、可重复测的自动审核。

## 我做了什么

- 按交付文档把规则、等级和报告格式落下来
- 搭主流程：解析 → 抽字段 → 规则审 / 模型审 → 汇总
- 提示词要求输出固定结构，后面用代码解析；前面失败就直接停，不硬审
- 准备分类样例，修时间写法不一致、计划为空却误判通过等问题

## 流程大概这样

```text
上传工作票 → 解析失败就停
         → 抽出字段，不是工作票就停
         → 规则审核 和 模型审核
         → 汇总等级和报告
```

## 难在哪

| 问题 | 怎么办 |
|------|--------|
| 票面写「至」，规则只认一种符号 | 先统一格式，再按时间段包含关系判断 |
| 计划为空却当成通过 | 计划空就明确判不通过 |
| 解析失败还继续审 | 直接短路，避免瞎出结论 |
