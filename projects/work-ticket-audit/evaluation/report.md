# 工作票审核 · 评测说明

## 方法

1. 准备 5 类虚构样例（通过 / 等级 / 人数 / 时间地点 / 措施冲突）
2. 每条给出期望字段与期望审核等级
3. 对照规则配置说明逐项核对报告区块是否齐全

## 可公开结论

| 项 | 结果 |
|----|------|
| 样例覆盖 | 5 类典型路径 |
| 报告模板对齐 | 基本信息 / 统计 / 合规清单 / 违规清单 |
| 时间区间误判修复 | 由「字符串比较」改为「区间包含 + 多分隔符」 |
| plan 空值 | 由静默通过改为明确不通过 |

精确端到端准确率依赖客户环境与票面 OCR 质量，**此处不填写未在公开环境复测的百分比**。

## Bad Case 复盘（思想）

遇到单条失败时先问：

1. 换一张票还会不会出现？
2. 空值是否有 code 兜底？
3. 用户是否看到明确原因？
4. 文档是否要求「审核需带任务计划」？
