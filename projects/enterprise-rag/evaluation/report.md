失败例思路：口语问法召回 chunk 未覆盖金标准片段 → 回查分块边界 / 改写 / 检索 top_k，而不是只改这一题的 prompt。

## 评测体系（可迁移）

1. **出题**：基于知识库构造标准问答（含混淆主体、口语、无主体、库外）  
2. **记录节点**：路由、实体、chunk、判定器状态  
3. **打分**：与标准答案对照（可辅以 LLM judge）  
4. **归类修复**：按错误节点类型改规则，再回归

主体张冠李戴的修复：质量判定要求「文档名 + 正文」同时锚定实体，否则 weak / 继续检索。
