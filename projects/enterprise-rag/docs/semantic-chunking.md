# 滑动窗口语义分块（方案 B）

## 为什么要做

- 内网 embedding **硬顶 512 token**  
- 红头文件 / 规章大量**无标题**，只按 `#` 会得到超长或过碎块  
- 固定长度会切断同一话题，或把附录粘在正文后

## 算法直觉

在两个句子之间的「缝」上，左右各取一段完整语境做向量，相似度低 → 更像话题边界。

```text
防护员要提前到岗。 | 作业人员不得侵限。 | 附件：表格样式如下……
         缝A（同话题，高相似）      缝B（正文→附录，低相似）
```

## 阈值

禁止拍脑袋 `0.7`。对本批所有缝的相似度排序，取分位数（如 P20）作为 τ，再结合邻域中位数抑制噪声。

## 长度门闩（示意）

| 条件 | 动作 |
|------|------|
| 块过短（如 &lt;100 token） | 即使相似低也不切 |
| 接近语义目标长度 | 允许按候选切点切开 |
| 接近硬顶（如 ~500） | 强制硬切，保证可 embed |
